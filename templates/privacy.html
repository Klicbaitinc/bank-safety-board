Privacy

The Bank Safety & Savings Board is a static website. There are no accounts and no login.

This site does not set cookies of its own. It does not run analytics or advertising scripts. Search runs in your browser against a file this site already published. The query is not sent to a server here.

The pages are hosted on GitHub Pages. GitHub may log your IP address and ordinary request data while serving the site.

If a newsletter link is shown, the signup page belongs to that provider. Their policy applies after you leave this site. No newsletter is offered while the newsletter URL in the site configuration is empty.

If you open an affiliate link, that site may set its own cookies. That happens after you leave this site.
